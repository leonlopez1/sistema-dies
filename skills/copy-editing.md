# SKILL: Edición y Mejora de Copy — Consultoría Estratégica

## Propósito
Revisar, pulir y mejorar textos de marketing y ventas para que sean más claros, persuasivos y efectivos. Diagnóstico primero, corrección después.

## Proceso de edición en 4 pasos

### Paso 1: Diagnóstico rápido
Responder estas preguntas antes de editar:
- ¿El hook detiene el scroll? (¿Qué tan fuerte es la primera línea?)
- ¿Hay buzzwords vacíos? (sinergia, potenciar, robusto, disruptivo, apalancar)
- ¿Hay números concretos o todo es vago?
- ¿El tono suena a humano o a plantilla?
- ¿El CTA es claro y accionable?
- ¿La lectura en voz alta suena natural en Colombia?

### Paso 2: Cirugía del hook
El hook es el 80% del trabajo. Si el hook falla, nada más importa.

**Señales de hook débil:**
- Empieza con pregunta retórica genérica
- Usa el nombre del servicio en la primera línea
- Es una declaración obvia o predecible
- No tiene un número, dato, o elemento de sorpresa

**Técnicas para fortalecer:**
- Agregar número específico + consecuencia inesperada
- Reemplazar "¿Sabías que...?" por declaración afirmativa fuerte
- Usar la técnica de "película en marcha": comenzar en el medio de la acción
- Crear tensión entre lo que se espera y lo que pasó

### Paso 3: Limpieza de cuerpo
**Eliminar:**
- Párrafos que dicen lo mismo que el anterior
- Adjetivos que no agregan información ("excelente", "increíble", "único")
- Frases de relleno ("Es importante mencionar que...", "Cabe destacar que...")
- Voz pasiva cuando la activa es posible
- Conectores débiles ("también", "además", "asimismo")

**Fortalecer:**
- Reemplazar lo genérico con lo específico
- Agregar ejemplos concretos del sector
- Convertir afirmaciones en mini-historias
- Usar verbos de acción ("implementar", "medir", "reducir") en vez de sustantivos vagos ("implementación", "medición")

### Paso 4: Optimizar CTA
**CTA débil:** "Si te interesa, no dudes en contactarme"
**CTA medio:** "¿Quieres saber más? Escríbeme por DM"
**CTA fuerte:** "¿Tu negocio tiene este problema? Cuéntame en qué sector estás y te mando el diagnóstico gratuito"

## Tabla de reemplazos comunes

| Palabra/frase débil | Reemplazo sugerido |
|---|---|
| potenciar | mejorar / multiplicar / escalar |
| apalancar | usar / aprovechar / capitalizar |
| sinergia | trabajo conjunto / combinación |
| disruptivo | diferente / nuevo / que rompe con |
| robusto | sólido / confiable / que funciona |
| ecosistema | red / sistema / conjunto |
| holístico | completo / integral / de cabo a rabo |
| impactar | afectar / cambiar / transformar |
| paradigma | forma de hacer / modelo / manera |
| tracción | avance / crecimiento / momentum |
| "en el día a día" | "en la operación diaria" / "cada semana" |
| "a nivel" | eliminar — "a nivel estratégico" → "estratégicamente" |
| "lo que les permite" | para que / y así / y con eso |

## Checklist final antes de publicar

### Para LinkedIn
- [ ] Primera línea funciona sola (sin el resto del texto)
- [ ] Ningún párrafo tiene más de 3 líneas
- [ ] Hay un número concreto en el texto
- [ ] No hay más de 2 emojis
- [ ] El CTA pide una sola cosa
- [ ] Hashtags: 3-5 relevantes, al final
- [ ] Lectura en voz alta < 90 segundos

### Para email
- [ ] Subject line tiene menos de 50 caracteres
- [ ] El primer párrafo justifica seguir leyendo
- [ ] No hay más de 1 enlace
- [ ] Un solo CTA
- [ ] El email se puede leer en 45 segundos
- [ ] Tono personal (no corporativo)

### Para propuestas
- [ ] El problema está descrito antes de la solución
- [ ] Los precios están anclados (más caro primero)
- [ ] Hay al menos 1 caso de éxito del mismo sector
- [ ] Los entregables son específicos y medibles
- [ ] Hay urgencia real (no artificial)
- [ ] El siguiente paso está claro

## Ejemplo de edición: antes y después

**ANTES:**
"En el competitivo mundo empresarial de hoy, es crucial para las PYMEs colombianas potenciar sus capacidades operativas y apalancar sus recursos de manera estratégica para lograr un crecimiento sostenible y rentable en el largo plazo."

**DESPUÉS:**
"La mayoría de PYMEs en Colombia crecen en ventas pero no en utilidad. El problema casi siempre está en la operación, no en el mercado."
